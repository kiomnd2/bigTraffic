# 변경 보고서 - Room 도메인 구현

**작성일**: 2026-02-23 22:08:00

## 개요
사용자간 AccountBook(가계부)을 공유하기 위한 "방(Room)" 기능을 DDD 4-Layer 아키텍처에 맞춰 구현하였다.
방 생성, 초대 코드 기반 참여, 멤버 관리, 가계부 연결 기능을 포함한다.
